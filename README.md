# Mortal Ender Chests

Makes Ender Chest inventories drop on death

## Configuration

- `drop_slots`: How many items should be dropped on death (any value bigger than the amount of filled slots will drop all items, default 27)
- `only_players`: Only drop items if the cause of death was by another player (default true)
- `respect_keep_inventory`: Don't drop Ender Chest items if keep inventory is on (default true)
